14 / 11 / 2024 · Praha

查理大桥的第七座雕像

雾里的查理大桥一个游客都没有,只有三十尊雕像和我。我突然觉得,它们等的,其实从来都是这样的清晨。

Read More

一个卖热红酒的婆婆,是那天桥上除了我之外,第一团有温度的影子。她从盖着厚呢子布的保温桶里,倒出一杯深紫红色的液体,递给我时笑着说了一句我听不懂的捷克语。我举杯朝她致意,那杯酒的温度,一直从我手心暖到了眼眶。后来我走过了查理大桥的每一座雕像,在第七座前停了很久——那是圣约翰·内波穆克,据说触摸他的浮雕会再回布拉格。我伸手摸了。我希望那个传说,是真的。

02 / 07 / 2024 · Amalfi

柠檬比日落先成熟

阿马尔菲的柠檬大得像一场误会。我抱着一颗走在盘山小路上,路过的每个老奶奶都对我笑。

Read More

那家小馆子没有菜单,老板看我一个人,端上来一道柠檬意大利饭,一道煎剑鱼,和一杯冰凉的白葡萄酒。他说,这是“只给今天来的人的菜”。海就在台阶下面三十米,一层浪一层浪地拍着,像一个人慢慢地翻一本没有字的书。我吃到一半的时候,日落刚好开始。橙红色的光落在我的柠檬饭上,我突然觉得,这一盘饭,比我很多年里任何一盘都要好吃。也许不是因为厨师更好,是因为我在对的时间,对的海边,对的一颗柠檬下面。

23 / 03 / 2024 · La Habana

哈瓦那的老爷车还没熄火

一辆1957年的雪佛兰,副驾窗外是风,风里是雪茄味,雪茄味里是半个世纪以前的一首歌。

Read More

我的司机叫Leo,他说这辆车比他大六岁。“她是我父亲留给我的。”他拍了拍方向盘,像拍一头老伙计的脖子。我们沿着Malecón大道开,海风吹得我头发都往后贴,两边的建筑像调色盘被谁打翻了。每开过一条街,都有人探出头来和Leo打招呼,Leo也一路挥着手,像他是哈瓦那的市长。临走的时候我多给了他一点小费,他笑着拒绝了一半,然后从口袋里掏出一张折得很旧的黑白照片给我看——那是他十七岁,坐在同一辆车里,同一个位置,留着当时最时髦的鬓角。时间有时候就是这么温柔的东西:它把车漆吹旧了,把路磨老了,但是把一个人最开心的样子,替他好好留着。

07 / 06 / 2024 · Valensole

瓦朗索勒的雾没散之前

凌晨五点半的薰衣草田,连蜜蜂都还没起。雾在紫色上面飘,像一层怕吵醒谁的呼吸。

Read More

我一个人站在齐腰的紫色中间,第一次觉得“静”不是一种感觉,是一种有重量的东西——它轻轻地落在肩上,你不觉得重,但是你知道它在。然后第一缕阳光从远处的圣维克多山后面爬上来,紫色的花尖一颗一颗地被点亮,像一只看不见的手,在田垅之间慢慢地点亮一排蜡烛。那天我没有拍太多照片。很多时候我只是站着,呼吸,听自己的呼吸声,再听远处一只最早起来的云雀。旅行最珍贵的,我后来想,从来不是“我去过”。是那五分钟——那五分钟里你什么都没有做,只是被世界温柔地,放在了它的一个角落里。
